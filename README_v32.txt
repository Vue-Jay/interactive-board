OnlineRepetitor v32 — большой патч совместной работы

Что добавлено:
- видно, какие объекты выбраны другими участниками;
- вокруг удалённо выбранного объекта появляется отдельная рамка с именем;
- если другой пользователь редактирует объект, рамка становится пульсирующей и подписывается «редактирует»;
- двойной щелчок по объекту, который уже редактирует другой участник, не открывает второй редактор и показывает уведомление;
- в верхней панели показывается количество участников, которые прямо сейчас редактируют объекты;
- в меню «В сети» видно состояние пользователя: «редактирует объект» или количество выбранных объектов;
- удалённые состояния автоматически очищаются при выходе пользователя или если состояние устарело.

Надёжность потока:
- board-work является отдельным низкочастотным каналом awareness;
- состояние отправляется только при изменении выделения/редактирования;
- debounce 80 мс;
- одинаковые состояния повторно не отправляются;
- курсоры board-cursors и управление экраном board-view не меняются;
- malformed сообщения игнорируются;
- stale-состояния удаляются через 15 секунд.
SQL не нужен.

Установка:
node install_v32.mjs
npm run build

Если сборка успешна:
git add .
git commit -m "v32: add collaborative editing awareness"
git push

Проверка:
1. Открыть одну доску двумя аккаунтами.
2. На первом выбрать объект. На втором должна появиться рамка с именем.
3. На первом открыть редактирование текста/стикера. На втором подпись меняется на «редактирует».
4. Попытаться вторым аккаунтом дважды щёлкнуть по этому объекту. Должно появиться уведомление вместо второго редактора.
5. Закрыть редактирование и проверить, что статус исчезает.
