OnlineRepetitor v71 — безопасная очистка Storage при окончательном удалении

Что изменилось:
- перед окончательным удалением сервер проверяет владельца, корзину и название;
- приложение считает файлы доски в приватном board-assets;
- все файлы с префиксом boardId/ удаляются пакетами;
- только после успешной очистки Storage сервер разрешает удалить запись доски;
- если очистка файлов не завершилась, сама доска остаётся в корзине и операцию можно повторить;
- политика Storage разрешает владельцу очищать вложения своей доски из корзины.

Установка:
1. Извлечь содержимое в корень проекта.
2. node install_v71.mjs
3. Выполнить supabase/v71_trash_storage_cleanup.sql.
4. npm run build

После успешной сборки:
git add .
git commit -m "v71: safely purge board storage"
git push

Автоматическое удаление по истечении 30 дней ещё не включено: для фонового запуска нужен серверный планировщик/service-role. Ручное окончательное удаление теперь очищает Storage безопасно.
