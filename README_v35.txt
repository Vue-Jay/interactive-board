OnlineRepetitor v35 — большой старт блока «Ученики»

Добавлено сразу:
- новый раздел «Ученики» на главном экране;
- единый список учеников, собранный из участников всех ваших досок;
- поиск по имени, email и тегам;
- карточка ученика;
- количество связанных досок;
- дата последней активности по доскам;
- список всех досок конкретного ученика;
- быстрый переход из карточки ученика прямо на нужную доску;
- личные заметки преподавателя;
- теги ученика, например «9 класс, алгебра, ЕГЭ»;
- адаптация раздела под узкий экран;
- заготовлены вкладки «Расписание» и «Материалы» для следующих больших этапов.

На этом этапе заметки и теги хранятся локально у преподавателя. Это специально: не добавляем небезопасные таблицы в Supabase без отдельной миграции/RLS. Следующий серверный этап сможет перенести их в защищённую таблицу.

SQL не нужен.

Установка:
node install_v35.mjs
npm run build

Если сборка успешна:
git add .
git commit -m "v35: add student management"
git push
