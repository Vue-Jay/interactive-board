OnlineRepetitor v79 — завершение и защита уведомлений

Что меняется:
- настройки уведомлений сохраняются через защищённый RPC пользователя;
- обычный authenticated-клиент больше не может вручную запускать глобальный генератор напоминаний;
- внутренний helper notification_enabled закрыт от прямого вызова клиента;
- pg_cron запускает напоминания на сервере каждые 15 минут;
- непрочитанный счётчик на главной обновляется раз в минуту и при возврате во вкладку;
- экран уведомлений также автоматически обновляется;
- service-role ключ в браузере НЕ используется.

Порядок:
1. Распаковать архив в корень.
2. node install_v79.mjs
3. В Supabase SQL Editor выполнить supabase/v79_notifications_finish.sql
4. npm run build

После успешной проверки:
git add .
git commit -m "v79: finish secure notifications"
git push

Если pg_cron недоступен в проекте, SQL Editor покажет ошибку на create extension / cron.schedule.
В таком случае пришлите её, не заменяйте cron вызовом из браузера.
