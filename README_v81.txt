OnlineRepetitor v81 — первый полноценный слой ролей аккаунта

Добавлено:
- роль аккаунта teacher / student хранится в profiles;
- защищённые RPC чтения и изменения собственной роли;
- выбор роли в профиле;
- роль меняет кабинет и навигацию;
- ученику скрываются преподавательские разделы «Ученики», «Прогресс», «Материалы»;
- прямой переход ученика в эти разделы больше не открывает преподавательский экран;
- задания, расписание, доски, шаблоны и уведомления остаются доступны;
- роль аккаунта НЕ заменяет owner/editor/viewer конкретной доски;
- существующие аккаунты получают teacher, чтобы обновление ничего не сломало;
- локальный режим тоже поддерживает роль.

Это фундамент. Следующий патч разделит сами экраны заданий/расписания на teacher/student UX и усилит серверные ограничения.

Порядок:
node install_v81.mjs
В Supabase SQL Editor выполнить supabase/v81_account_roles.sql
npm run build

После успешной проверки:
git add .
git commit -m "v81: add teacher and student account roles"
git push
