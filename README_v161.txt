OnlineRepetitor v161

Исправление сделано поверх актуального remote main v160, без отката файлов.

Главное:
- верхняя панель принудительно остаётся видимой на всех viewport до 1100 px;
- убрано конфликтующее поведение старых mobile media rules;
- слева всегда постоянная колонка инструментов, в portrait и landscape;
- кнопка мобильного drawer больше не заменяет колонку;
- в шапке всегда остаются основные collaborative controls;
- служебные надписи сохранения/online скрыты;
- индикатор: зелёный online, жёлтый reconnecting, красный offline;
- рядом с индикатором всегда число участников;
- Play, добавить участника, чат и меню остаются компактными;
- второстепенные desktop-кнопки не наслаиваются на шапку.
