OnlineRepetitor v75 — мультимедиа по ссылкам, без расхода Storage

Сделано:
- новый объект «Видео / аудио по ссылке»;
- внутренний YouTube-плеер через youtube-nocookie;
- внутренний Vimeo-плеер;
- встроенный HTML5 audio для прямых MP3/M4A/AAC/OGG/WAV/FLAC ссылок;
- встроенный HTML5 video для прямых MP4/WebM/OGV/MOV/M4V ссылок;
- неизвестные/невстраиваемые сайты отображаются безопасной карточкой со ссылкой;
- YouTube/Vimeo iframe загружается только после нажатия Play, экономя трафик и ресурсы;
- редактирование URL и названия у уже созданного объекта;
- открытие исходной ссылки;
- объект хранит только URL и название, медиафайл не попадает в Supabase Storage;
- мультимедиа сохраняется в документе, истории, .orboard и .orworkspace автоматически;
- горячая клавиша L / Д.

SQL не нужен.

Установка:
1. Извлечь архив в корень проекта.
2. node install_v75.mjs
3. npm run build

После успешной сборки:
git add .
git commit -m "v75: add linked multimedia player"
git push
