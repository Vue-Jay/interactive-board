OnlineRepetitor v26 — присутствие пользователей

Небольшой следующий этап совместной работы.

Добавлено:
- список пользователей, которые прямо сейчас находятся на открытой доске;
- имя пользователя;
- его роль: владелец / редактор / просмотр;
- счётчик "В сети N" в верхней панели;
- автоматическое появление и исчезновение пользователя при входе/выходе;
- переподключение Presence после обрыва соединения.

Важно:
- это пока только Presence, без живых курсоров;
- координаты мыши здесь специально не передаются;
- SQL выполнять не нужно;
- существующая синхронизация содержимого доски не заменяется и не меняется.

Установка:
1. Распакуйте архив прямо в корень проекта C:\Users\user\InteractiveBoard
   После этого должны появиться:
     src\boardPresence.ts
     install_v26.mjs
2. В терминале из корня проекта выполните:
     node install_v26.mjs
3. Затем:
     npm run build
4. Если сборка успешна:
     git add .
     git commit -m "v26: add realtime board presence"
     git push

Проверка:
- откройте одну доску в двух разных аккаунтах/браузерах;
- в верхней панели нажмите "В сети 2";
- оба пользователя должны быть видны в списке.

Следующий этап по плану: живые курсоры через Realtime Broadcast,
после чего добавим "Переместить ко мне", "Собрать всех" и следование за преподавателем.
