OnlineRepetitor v38: живой режим урока.

Добавлено: начало урока, выбор присутствующего ученика, тема, серверный активный урок, таймер, восстановление после перезагрузки, завершение с итогом и домашним заданием, автоматическая запись в историю ученика, RLS и ограничение одного активного урока на доску.

Установка:
1. Скопировать файлы.
2. Выполнить supabase/v38_live_lessons.sql в Supabase SQL Editor.
3. node install_v38.mjs
4. npm run build
5. git add .
   git commit -m "v38: add live lesson mode"
   git push
