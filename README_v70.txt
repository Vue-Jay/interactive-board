OnlineRepetitor v70 — защита корзины

Добавлено:
- корзина загружается через отдельную защищённую RPC-функцию;
- сервер возвращает срок хранения: 30 дней после удаления;
- окончательное удаление требует точного ввода названия доски;
- проверка названия выполняется и в интерфейсе, и на сервере;
- старый RPC окончательного удаления без подтверждения удаляется.

Важно:
30-дневный срок пока информационный. Автоматическое физическое удаление намеренно НЕ включено,
пока не будет безопасно решена очистка файлов доски из приватного Supabase Storage.
Так мы не оставим скрытые файлы-сироты и не потеряем данные раньше времени.

Установка:
1. Извлечь архив в корень проекта.
2. node install_v70.mjs
3. Выполнить supabase/v70_trash_safety.sql в Supabase SQL Editor.
4. npm run build

После успешной сборки:
git add .
git commit -m "v70: harden board trash safety"
git push
