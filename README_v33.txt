OnlineRepetitor v33 — совместная работа, часть 2

ВАЖНО: этот патч ставится поверх v32. GitHub main на момент подготовки ещё содержит v31, поэтому сначала должен быть установлен предыдущий архив v32.

В одном патче:
- видно, когда другой пользователь ПЕРЕМЕЩАЕТ объект;
- видно, когда он МЕНЯЕТ РАЗМЕР;
- видно, когда он ПОВОРАЧИВАЕТ объект;
- над занятым объектом появляется компактная подпись с именем и действием;
- другой пользователь не может начать конфликтующее действие с тем же объектом, пока тот занят;
- блокировка действует и на текстовое редактирование из v32;
- для групповых resize/rotate передаётся весь набор активных объектов;
- после окончания жеста состояние занятости сразу сбрасывается;
- меню «В сети» показывает текущее действие участника;
- устаревшие awareness-состояния по-прежнему очищаются автоматически.

Поток:
- новый WebSocket НЕ добавляется;
- расширяется существующий board-work из v32;
- board-cursors и board-view не меняются;
- положение объекта не стримится отдельными сообщениями, поэтому мы не создаём второй тяжёлый поток координат;
- серверная синхронизация документа остаётся источником фактического состояния доски.

SQL не нужен.

Установка:
node install_v33.mjs
npm run build

Если сборка успешна:
git add .
git commit -m "v33: improve collaborative editing safety"
git push

Проверка:
1. Открыть доску двумя аккаунтами.
2. Первым аккаунтом начать тянуть объект.
3. На втором должна появиться подпись «имя · перемещает».
4. Пока первый держит объект, вторым попробовать схватить его. Должно появиться уведомление, действие не начинается.
5. Повторить для resize и rotate.
6. Отпустить объект. Занятость должна исчезнуть.
