OnlineRepetitor v68 — история версий доски

Добавлено:
- серверные снимки при каждом успешном сохранении;
- до 100 последних версий на доску;
- окно «История» прямо на доске;
- дата, номер версии и количество объектов;
- восстановление старой версии;
- восстановленная версия сохраняется как новое состояние, история не уничтожается;
- viewer может просматривать историю, но не восстанавливать.

Установка:
1. Извлечь содержимое архива в корень проекта.
2. node install_v68.mjs
3. Выполнить supabase/v68_board_history.sql в Supabase SQL Editor.
4. npm run build

После успешной сборки:
git add .
git commit -m "v68: add board version history"
git push

Важно: история начинает накапливаться после установки SQL v68. Старые версии, которые ранее нигде не сохранялись, восстановить задним числом невозможно.
