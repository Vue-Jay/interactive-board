OnlineRepetitor v76 — доведение шаблонов и интеграции v75

Патч:
- подключает полноценный экран пользовательских шаблонов в основную маршрутизацию;
- добавляет «Шаблоны» в главное меню кабинета;
- сохраняет существующую быструю панель встроенных шаблонов внутри доски;
- добавляет мультимедиа по ссылке в памятку горячих клавиш;
- Enter/F2 для выбранного ссылочного мультимедиа открывает редактор URL;
- небольшая адаптация сетки пользовательских шаблонов.

SQL не требуется.

Установка:
node install_v76.mjs
npm run build

После успешной сборки:
git add .
git commit -m "v76: finish templates integration"
git push
