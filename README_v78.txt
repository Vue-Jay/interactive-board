OnlineRepetitor v78 — публичная презентация доведена до рабочего viewer-режима

Важно:
проверка GitHub после v77 показала, что commit v77 есть, но изменения App.tsx и ShareDialog.tsx фактически не попали в main. Поэтому v78 не предполагает, что v77 уже встроен: он восстанавливает его изменения и сразу завершает viewer-режим.

Сделано:
- viewer-ссылка может иметь отдельный вариант ?present=1;
- параметр presentation сохраняется после гостевого/парольного входа;
- viewer автоматически открывает первый фрейм;
- чистый режим без верхней панели, инструментов, миникарты и редактирования;
- публичному зрителю оставлены только предыдущий/следующий слайд, список слайдов и fullscreen;
- скрыты таймер преподавателя, лазер, прожектор, ответы тестов, сброс заданий, blackout, заметки преподавателя, PNG-экспорт и кнопка выхода из показа;
- Esc не выбрасывает viewer из публичной презентации;
- стрелки, PageUp/PageDown, Home/End продолжают переключать слайды;
- адаптация панели и списка слайдов под телефон;
- SQL не требуется.

Установка:
node install_v78.mjs
npm run build

После успешной проверки:
git add .
git commit -m "v78: finish public presentation viewer"
git push
