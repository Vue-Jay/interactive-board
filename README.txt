OnlineRepetitor — автоматическая совместная синхронизация

Этот патч убирает пользовательский выбор «серверная / моя версия».
При одновременной работе изменения синхронизируются автоматически:
- новый серверный снимок принимается как свежая база;
- локально изменённые/созданные объекты накладываются поверх;
- локальные удаления сохраняются, если тот же объект не был одновременно изменён удалённо;
- объединённое состояние автоматически отправляется на сервер;
- баннер «Обнаружены параллельные изменения» и панель резервной копии больше не показываются.

ВАЖНО: сначала должен быть установлен предыдущий патч onlinerepetitor_collab_view_hotfix,
чтобы положение экрана вообще не участвовало в совместных изменениях.

Установка:
node install_live_merge_hotfix.mjs
npm run build

SQL не нужен.

После проверки:
git add .
git commit -m "fix: auto-merge concurrent board updates"
git push
