OnlineRepetitor — hotfix совместной навигации

Исправляет две связанные ошибки:
1. Экран ученика мог перемещаться вслед за преподавателем даже при выключенном личном следовании.
2. Простое панорамирование/масштабирование считалось изменением документа, отправлялось на сервер и могло вызывать баннер «Обнаружены параллельные изменения».

После исправления:
- viewport каждого участника локальный;
- панорамирование и zoom не создают серверную версию;
- realtime-обновление объектов не перетаскивает экран другого участника;
- личное «Следовать за преподавателем» работает только когда включено;
- «Вести всех» временно принудительно включает следование, но после отключения возвращается прежний личный режим;
- явные команды «Ко мне» / «Собрать всех» по-прежнему могут разово переместить экран, как и задумано.

Установка:
node install_collab_view_hotfix.mjs
npm run build

SQL не нужен.

После успешной проверки:
git add .
git commit -m "fix: decouple viewport from collaborative board state"
git push
