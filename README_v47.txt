OnlineRepetitor v47 — исправление интеграции шаблонов + вложения

Этот патч специально исправляет v46:
- v46-файлы попали в репозиторий, но его install_v46.mjs содержал синтаксическую ошибку и не встроил экран шаблонов в App.tsx;
- v47 корректно подключает раздел «Шаблоны» и навигацию;
- на доске появляется кнопка «Шаблон»;
- шаблон сохраняет структуру текущей доски;
- изображения и PDF теперь копируются в отдельный приватный Storage bucket template-assets;
- при создании доски из шаблона вложения автоматически копируются в board-assets новой доски;
- исходная доска и шаблон остаются независимыми;
- удаление шаблона очищает его template-assets;
- RLS ограничивает template-assets текущим пользователем.

Установка:
1. Выполнить supabase/v47_template_assets.sql.
2. node install_v47.mjs
3. npm run build
4. После успешной сборки:
   git add .
   git commit -m "v47: finish templates with assets"
   git push
