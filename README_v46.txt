OnlineRepetitor v46 — шаблоны занятий

Добавлено:
- новый раздел «Шаблоны»;
- сохранение текущей доски как собственного шаблона;
- название, категория и описание;
- поиск и фильтр категорий;
- создание новой доски из шаблона одним нажатием;
- содержимое доски копируется, исходный шаблон не меняется;
- счётчик использования;
- удаление шаблонов;
- серверное хранение и RLS.

Важно: v46 сохраняет структуру доски. Вложения PDF/изображений, которые существуют только в board-assets исходной доски, пока не дублируются в шаблон. Это следующий этап, чтобы не делать скрытых битых ссылок.

Установка:
1. Выполнить supabase/v46_templates.sql.
2. node install_v46.mjs
3. npm run build
4. git add .
   git commit -m "v46: add lesson templates"
   git push
