OnlineRepetitor v66 — имя гостя + пароль ссылки

Извлеките содержимое архива в корень проекта с сохранением папки supabase/.

1. node install_v66.mjs
2. Supabase SQL Editor: выполнить supabase/v66_share_link_password.sql
3. npm run build

После успешной сборки:
git add .
git commit -m "v66: add guest names and share link passwords"
git push

Добавлено:
- гость вводит отображаемое имя перед входом;
- имя сохраняется в анонимной Supabase-сессии и используется в присутствии/интерфейсе;
- владелец может защитить новую ссылку паролем;
- пароль хранится на сервере только как bcrypt-хэш;
- активные защищённые ссылки помечаются замком;
- срок и лимит входов продолжают работать.

Примечание: ввод пароля при открытии защищённой ссылки будет завершён следующим патчем вместе с отдельным экраном проверки доступа.
