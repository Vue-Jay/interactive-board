OnlineRepetitor v206 LOCAL

Next role-permission stage.

Students can still USE teacher learning objects:
- tick checklist answers;
- choose quiz answers;
- flip flashcards;
- open/close covers.

But students can no longer structurally modify teacher learning/material objects:
- no moving them with Smart Hand;
- no resize/rotate handles;
- no deletion;
- no duplication/lock controls;
- no teacher editing controls, colors or typography for protected learning objects.

Protected kinds:
frame, table, formula, graph, checklist, quiz, flashcard, cover, link-media.

Normal student work remains available:
pen, marker, eraser, text, sticky notes, comments and approved media workflow.

v205 mobile drag fix is retained for ordinary movable objects and approved attachments.

QA:
npm run build
npm run dev

Two-account check:
Teacher creates quiz/checklist/flashcard/cover.
Student can answer/use each one but cannot move, resize, rotate, delete or edit its structure.
