OnlineRepetitor v88 — расширенная история изменений

Что изменено:
- история теперь показывает автора каждого серверного сохранения;
- для каждой версии считается сводка относительно предыдущей: сколько объектов добавлено, изменено и удалено;
- восстановление старой версии осталось безопасным: оно создаёт новое состояние и не стирает историю;
- история по-прежнему хранит до 100 серверных снимков.

Перед запуском выполните в Supabase SQL Editor:
supabase/v88_rich_board_history.sql

Затем:
npm run build
git add .
git commit -m "v88: expand board change history"
git push origin main
