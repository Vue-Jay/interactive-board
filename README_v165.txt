OnlineRepetitor v165

Мобильная панель инструментов пересобрана по группам:
1. Навигация: Рука, Выделение.
2. Быстрое создание: Карандаш, Стикер, Текст, Фигуры.
3. Кнопка + открывает полный каталог с группами:
   Навигация / Рисование / Создание / Материалы / Учёба.

Для landscape:
- основной dock в одну строку;
- кнопки 40x40 px;
- полный каталог открывается широкой сеткой по 8 элементов;
- панель не забирает высоту холста.

Навигация «Всё / Выбор»:
- между активными кнопками 16 px в landscape;
- если «Выбор» недоступен, он полностью скрывается вместо полупрозрачного наложения.

Полные файлы для замены.
