Исправление v65.

Причина ошибки: предыдущий установщик записал последовательности \n в TypeScript как обычные символы.
Этот hotfix удаляет их и корректно завершает установку гостевого входа.

1. Извлеките файлы в корень проекта.
2. node install_v65_hotfix1.mjs
3. npm run build

SQL не требуется. Ничего вручную в src менять не нужно.
