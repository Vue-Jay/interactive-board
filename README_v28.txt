OnlineRepetitor v28 — «Переместить ко мне»

Что добавлено:
- у владельца доски рядом с каждым другим пользователем онлайн появляется кнопка «Ко мне»;
- по нажатию экран выбранного пользователя перемещается к той области доски, которую сейчас видит преподаватель;
- сохраняется масштаб преподавателя;
- центр области пересчитывается под размер экрана ученика, поэтому функция работает корректнее на разных мониторах;
- ученик получает короткое уведомление о перемещении.

Надёжность:
- команда перемещения использует отдельный Realtime topic board-view;
- поток команд не смешивается с живыми курсорами;
- команда отправляется только по нажатию, поэтому канал низкочастотный;
- malformed/unrelated сообщения игнорируются;
- SQL не нужен.

Установка:
1. Распаковать архив в корень проекта.
2. Выполнить:
   node install_v28.mjs
3. Затем:
   npm run build
4. Если сборка успешна:
   git add .
   git commit -m "v28: add move student to teacher view"
   git push

Проверка:
- открыть одну доску преподавателем-владельцем и вторым аккаунтом;
- преподавателю открыть «В сети»;
- возле второго пользователя нажать «Ко мне»;
- второй экран должен перейти к той же области доски.

Следующий этап:
- «Собрать всех» одной кнопкой;
- затем постоянный режим «Следовать за преподавателем».
