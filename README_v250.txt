OnlineRepetitor v250

Финальная правка автоклавиатуры редакторов объектов:
- шаблоны формул больше не программно фокусируют поле ввода;
- вставка формулы из буфера больше не открывает клавиатуру;
- во всех редакторах объектов клавиатура появляется только после явного нажатия пользователя на поле ввода;
- автфокус остался только в не-объектных интерфейсах (поиск/палитра команд/пароль защищённой ссылки).
