OnlineRepetitor v138 - обычный звонок с опциональным видео

Сделано:
- функция теперь называется «Звонок», а не «Видеозвонок»;
- основная кнопка получила SVG-значок телефонной трубки;
- звонок начинается только с микрофоном, камера не запрашивается автоматически;
- видео включается отдельной кнопкой уже во время разговора;
- видео можно снова выключить, не завершая звонок;
- видеоканал резервируется WebRTC transceiver заранее, поэтому камера включается внутри текущего соединения;
- демонстрация экрана остаётся внутренней функцией звонка;
- service-worker cache обновлён до v138.

Проверка:
- TypeScript `tsc -b`: успешно.

Статус:
Клиентская логика звонков готова к реальному межсетевому тесту с coturn.
