OnlineRepetitor v27 — живые курсоры

Добавлено:
- курсор другого пользователя отображается на доске в реальном времени;
- рядом с курсором показывается имя пользователя;
- координаты передаются в координатах самой доски, поэтому курсор остаётся в правильном месте даже при разном масштабе и панорамировании;
- отправка ограничена примерно 20 обновлениями в секунду, чтобы не спамить Realtime;
- курсор исчезает, если пользователь покинул доску;
- старые курсоры автоматически очищаются;
- Presence v26 продолжает работать отдельно.

SQL выполнять не нужно.

Установка:
1. Распаковать архив в корень проекта C:\Users\user\InteractiveBoard
2. Выполнить:
   node install_v27.mjs
3. Затем:
   npm run build
4. Если сборка успешна:
   git add .
   git commit -m "v27: add live collaborative cursors"
   git push

Проверка:
- открыть одну доску двумя разными аккаунтами;
- двигать мышью в одном окне;
- во втором окне должен двигаться подписанный курсор первого пользователя.

Следующий небольшой этап:
- «Переместить ко мне» для отдельного ученика;
- затем «Собрать всех»;
- затем режим постоянного следования за преподавателем.
