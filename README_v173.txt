OnlineRepetitor v173

Исправлена именно доставка обновлений в установленное мобильное приложение.

- Обычный reload при несовпадении версии заменён на переход к versioned URL ?_appv=...
  Старый документ больше не может бесконечно перезагружать сам себя из HTTP-кэша.
- index.html проверяет /version.json ДО запуска React.
- React сохраняет вторую независимую проверку версии.
- Vercel временно отдаёт все ответы с no-store/no-cache, чтобы полностью исключить
  старые HTML/JS/CSS во время стабилизации мобильного приложения.
- Очистка старых Service Worker и Cache Storage сохранена.
- Версия приложения: 173.
- Центрирование landscape-панели сделано последним авторитетным CSS-правилом:
  left:0 + right:0 + auto margins. Старые правила right больше не могут её сдвинуть.
- Меню всех инструментов также центрируется.
