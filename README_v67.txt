OnlineRepetitor v67 — завершение защищённых ссылок + исправление отзыва

Исправлено:
- отозванная ссылка сразу исчезает из списка;
- сервер теперь вообще не возвращает отозванные, истёкшие и исчерпавшие лимит ссылки в списке активных;
- защищённая ссылка при открытии показывает отдельный запрос пароля;
- неверный пароль не теряет ссылку: можно ввести пароль повторно;
- отмена возвращает пользователя к его доскам.

Установка:
1. Извлечь содержимое архива в корень проекта.
2. node install_v67.mjs
3. Выполнить в Supabase SQL Editor: supabase/v67_share_link_cleanup.sql
4. npm run build

После успешной сборки:
git add .
git commit -m "v67: finish protected share links"
git push
