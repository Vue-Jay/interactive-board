OnlineRepetitor v83 — отдельные рабочие кабинеты ученика и преподавателя

После v82 роли больше не только контролируют допуск. v83 разделяет общий UX.

Ученик:
- не видит Ученики / Прогресс / Материалы;
- в Заданиях не получает преподавательские кнопки;
- не может создавать, удалять и проверять задания;
- видит только свою учебную логику сдачи и результата;
- в Расписании не может создавать, завершать и удалять занятия;
- может открыть доступную доску назначенного занятия.

Преподаватель:
- сохраняет полный кабинет;
- создаёт и проверяет задания;
- управляет расписанием;
- работает с учениками, прогрессом и материалами.

Сервер:
- review_assignment требует approved teacher/admin;
- INSERT/UPDATE/DELETE расписания требует approved teacher/admin через RLS.

Установка:
node install_v83.mjs
В Supabase SQL Editor выполнить supabase/v83_role_workspaces.sql
npm run build

После успешной проверки:
git add .
git commit -m "v83: split teacher and student workspaces"
git push
