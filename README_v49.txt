OnlineRepetitor v49 — центр уведомлений

События:
- новое задание ученику;
- ученик сдал работу преподавателю;
- преподаватель проверил работу;
- назначен материал;
- запланировано занятие.

Есть отдельный центр уведомлений, непрочитанные, «прочитать все» и переход к нужному разделу.
Уведомления создаются серверными триггерами, поэтому не зависят от того, открыт ли браузер.

Установка:
1. supabase/v49_notifications.sql
2. node install_v49.mjs
3. npm run build
4. git add .
   git commit -m "v49: add notification center"
   git push
