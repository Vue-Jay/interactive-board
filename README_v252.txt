OnlineRepetitor v252

Производительность вложений:
- изображения и PDF подгружаются только при приближении к видимой области доски;
- PDF теперь подключаются лениво через iframe вместо одновременного запуска всех встроенных viewer-объектов;
- добавлен ограниченный RAM-кэш Blob-вложений;
- повторные обращения к уже открытым файлам меньше нагружают IndexedDB;
- Media остаётся мемоизированным.

Интерфейс:
- поиск инструментов не открывает мобильную клавиатуру автоматически; ввод начинается только после нажатия на поле.
