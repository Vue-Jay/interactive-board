OnlineRepetitor v147
Исправление запуска установленного PWA с главного ярлыка.

Изменено:
- HTML-точка входа больше не кэшируется Service Worker.
- При запуске PWA всегда запрашивается актуальный index.html.
- Старые onlinerepetitor-* кэши удаляются при активации v147.
- start_url отделён от обычной вкладки параметром source=pwa.
- orientation изменена с landscape на any для корректного старта на телефоне.
- Хешированные Vite assets по-прежнему кэшируются.
