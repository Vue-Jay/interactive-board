OnlineRepetitor v39 — центр управления уроком

После запуска живого урока нажмите на карточку ученика/таймер в верхней панели.

Новая панель объединяет:
- текущего ученика, тему и живой таймер;
- «Ко мне» для экрана ученика;
- включение/выключение режима «Вести экран»;
- быстрый запуск презентации;
- паузу/продолжение секундомера;
- лазер и прожектор;
- список всех участников, которые сейчас на доске;
- отдельную кнопку «Ко мне» для каждого участника;
- быстрое завершение урока с переходом к итогам и домашнему заданию.

Патч использует уже существующие Presence, View Control, Presentation и Live Lesson. Новых таблиц и WebSocket-каналов нет.

Установка:
node install_v39.mjs
npm run build

После успешной сборки:
git add .
git commit -m "v39: add lesson control center"
git push
