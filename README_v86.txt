OnlineRepetitor v86 — уведомления обсуждений

Что добавлено:
- ответы в серверных обсуждениях создают уведомление автору исходного комментария;
- @упоминание по отображаемому имени создаёт уведомление участнику доски;
- уведомление открывает нужную доску;
- в настройках уведомлений появился отдельный переключатель «Ответы и упоминания в обсуждениях»;
- сервер учитывает этот переключатель до создания уведомления;
- автор комментария не получает уведомление сам о себе, а ответ + упоминание одного человека не дублируются.

Порядок:
1. Заменить файлы из архива в проекте.
2. Выполнить supabase/v86_comment_notifications.sql в Supabase SQL Editor.
3. npm run build
4. git add .
5. git commit -m "v86: add discussion notifications"
6. git push origin main

Упоминание: в тексте комментария напишите @Имя, где Имя точно совпадает с отображаемым именем пользователя в профиле. Имена с пробелами поддерживаются.
