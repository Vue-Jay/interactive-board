OnlineRepetitor v42 — расписание занятий

Добавлено:
- полноценный раздел «Расписание»;
- недельный календарь с переходом между неделями;
- занятие связано с учеником и доской;
- тема, дата/время, длительность, заметка;
- еженедельные серии на 2–24 недели;
- ближайшие занятия отдельным блоком;
- ученик видит назначенные ему занятия, но не может менять чужое расписание;
- преподаватель может отметить занятие завершённым;
- удаление одного занятия или всей серии;
- быстрый переход на доску перед уроком;
- подготовлена передача ученика и темы в sessionStorage для дальнейшей автосвязки со стартом Live Lesson;
- серверное хранение и RLS.

Установка:
1. Выполнить supabase/v42_schedule.sql в Supabase SQL Editor.
2. node install_v42.mjs
3. npm run build
4. После успешной сборки:
   git add .
   git commit -m "v42: add lesson schedule"
   git push
