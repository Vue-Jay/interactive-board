OnlineRepetitor v82 — одобрение преподавателей администратором

ВАЖНО: v81 должен быть уже установлен. Он подтверждён в main.

Что делает v82:
- пользователь больше НЕ может сам назначить себе роль преподавателя;
- запрос роли получает статус pending;
- только администратор может одобрить или отклонить запрос;
- есть отдельный экран «Администрирование» со списком заявок и историей;
- администратор может отозвать преподавательский доступ;
- до одобрения пользователь остаётся учеником;
- ученик не может создавать собственные доски, импортировать доски как свои или пользоваться шаблонами;
- запрет создания досок действует на сервере, а не только скрывает кнопку;
- прямой INSERT boards тоже закрыт RLS;
- создание/изменение личных шаблонов ограничено одобренными преподавателями;
- создание/изменение преподавательских заданий и карточек учеников дополнительно защищено;
- существующие teacher из v81 переводятся в pending, пока администратор их не подтвердит;
- app_admin всегда имеет преподавательские права.

УСТАНОВКА

1. Распаковать архив в корень проекта.
2. Выполнить:
   node install_v82.mjs

3. В Supabase SQL Editor выполнить целиком:
   supabase/v82_teacher_approval.sql

4. СРАЗУ ПОСЛЕ ЭТОГО назначить первый администраторский аккаунт.
   В SQL Editor выполнить, заменив YOUR_ADMIN_EMAIL на email вашего аккаунта:

   insert into public.app_admins(user_id)
   select id from auth.users
   where lower(email)=lower('YOUR_ADMIN_EMAIL')
   on conflict(user_id) do nothing;

   Важно: не вставляйте service_role ключ в приложение. Администратор определяется только серверной таблицей app_admins.

5. Перезагрузить приложение и выполнить:
   npm run build

6. Откройте «Настройки». У администратора должна появиться карточка «Администратор».
   На главной появится раздел «Администрирование».

7. Для проверки создайте второй обычный аккаунт:
   - он должен быть учеником;
   - «Новая доска» отсутствует;
   - запросить преподавателя можно из настроек;
   - после запроса он остаётся учеником;
   - заявка появляется у администратора;
   - только после «Одобрить» появляется преподавательский кабинет и создание досок.

После успешной проверки:
git add .
git commit -m "v82: require admin approval for teachers"
git push
