OnlineRepetitor v72 — переносимые резервные копии

Большой шаг по экспорту/импорту:
- новый формат .orboard;
- документ + изображения + PDF в одном переносимом файле;
- строгая проверка структуры и вложений;
- лимиты на размер и количество вложений;
- экспорт больше не молча пропускает отсутствующий файл;
- импорт сохраняет состояние «До импорта»;
- совместимость со старыми .board.json и обычными JSON сохранена;
- прогресс подготовки/импорта показывается в интерфейсе;
- после импорта вложения получают новые ID, чтобы не конфликтовать с существующими.

Установка:
1. Извлечь архив в корень проекта.
2. node install_v72.mjs
3. npm run build

SQL в этом патче не нужен.

После успешной сборки:
git add .
git commit -m "v72: improve portable board backups"
git push
