OnlineRepetitor v29 — «Собрать всех»

Добавлено:
- владельцу доски в меню «В сети» доступна кнопка «Собрать всех»;
- она перемещает экраны всех остальных присутствующих пользователей к текущей области преподавателя;
- масштаб преподавателя также передаётся;
- сам преподаватель из списка целей исключается.

Важно:
- новый Realtime-поток не создаётся;
- используется уже проверенный отдельный канал board-view из v28;
- каждая команда адресная, поэтому пользователь принимает только сообщение со своим targetUserId;
- поток живых курсоров board-cursors не затрагивается;
- SQL не нужен.

Установка:
1. Распаковать архив в корень проекта.
2. Выполнить:
   node install_v29.mjs
3. Затем:
   npm run build
4. Если сборка успешна:
   git add .
   git commit -m "v29: add gather everyone view control"
   git push

Проверка:
Откройте одну доску минимум в двух аккаунтах. Владелец открывает «В сети» и нажимает «Собрать всех». Остальные открытые экраны должны перейти к его текущей области.

Следующий этап:
постоянный режим «Следовать за преподавателем».
