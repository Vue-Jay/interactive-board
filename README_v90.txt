OnlineRepetitor v90 — комментарии и упоминания 100%

Что завершено:
- серверные ветки и ответы;
- Realtime-обновление открытого обсуждения;
- @упоминания участников доски;
- быстрые кнопки упоминания без ручного ввода имени;
- уведомления об ответах и упоминаниях с учётом личной настройки;
- уведомление ведёт прямо к нужной ветке;
- нужная ветка автоматически прокручивается в центр и подсвечивается;
- точные границы @имени: совпадение по префиксу больше не должно уведомлять другого пользователя;
- статусы «решено / открыть снова» остаются доступны редакторам.

Установка:
1. Заменить файлы из архива.
2. Выполнить supabase/v90_finish_discussions.sql в Supabase SQL Editor.
3. npm run build
4. git add .
5. git commit -m "v90: finish board discussions"
6. git push origin main
