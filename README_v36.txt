OnlineRepetitor v36 — история ученика и занятий

Большой патч блока «Ученики».

Добавлено:
- история занятий для каждого ученика;
- создание записи занятия;
- редактирование записи;
- удаление записи;
- дата занятия;
- привязка занятия к конкретной доске;
- длительность занятия;
- тема;
- итог / прогресс;
- домашнее задание;
- статистика в карточке: доски, число занятий, суммарное время, последняя активность;
- в списке учеников видно количество занятий;
- адаптивная форма для мобильного экрана.

Пока история хранится локально у преподавателя вместе с заметками/тегами. Это позволяет проверить UX без небезопасной серверной схемы. Серверная синхронизация карточек и истории будет отдельным этапом с RLS.

Установка:
1. Скопировать src из архива в проект с заменой.
2. Запустить:
   node install_v36.mjs
   npm run build

Если сборка успешна:
git add .
git commit -m "v36: add student lesson history"
git push

SQL не нужен.
