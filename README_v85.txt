OnlineRepetitor v85 · Обсуждения и ответы

Что добавлено:
- отдельные серверные обсуждения для каждой доски;
- ответы внутри ветки;
- @упоминания в тексте;
- статус «Решено» / возврат обсуждения;
- RLS: читать и писать могут только участники доски, закрывать обсуждения — автор/редактор/владелец;
- база для следующего шага: уведомления по @упоминаниям.

Установка:
1. Распакуйте ZIP в корень проекта с заменой файлов из архива.
2. Запустите:
   node install_v85.mjs
3. В Supabase SQL Editor выполните:
   supabase/v85_comment_threads.sql
4. Запустите:
   npm run build

Если SQL сообщит, что в profiles нет full_name, пришлите текст ошибки: схема профиля в разных ветках проекта менялась, подстроим триггер под фактическую колонку.
