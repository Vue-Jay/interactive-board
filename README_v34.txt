OnlineRepetitor v34 — безопасное разрешение конфликтов

Большой патч надёжности совместной работы.

Добавлено:
- при конфликте локальная версия отдельно сохраняется как резервная копия;
- пользователь видит номер конфликтующей серверной версии;
- «Серверная версия» больше не означает безвозвратную потерю локального варианта;
- после применения серверной версии локальный вариант можно восстановить;
- резервную копию можно скачать отдельным JSON;
- резервную копию можно удалить вручную после проверки;
- «Сохранить мою» теперь выполняет отдельную серверную запись с expectedVersion;
- если за время выбора сервер изменился ЕЩЁ РАЗ, приложение не перезаписывает его вслепую, а показывает новый конфликт;
- при недоступном сервере локальная резервная копия остаётся;
- добавлено раскрываемое объяснение действий прямо в конфликтной панели;
- кнопки блокируются на время разрешения конфликта.

Это не создаёт новых Realtime-каналов и не увеличивает поток курсоров/awareness.
SQL не нужен.

Установка:
node install_v34.mjs
npm run build

Если сборка успешна:
git add .
git commit -m "v34: add safe conflict recovery"
git push

Проверка конфликта:
1. Открыть доску двумя редакторами.
2. Почти одновременно внести разные изменения.
3. На стороне конфликта должна появиться новая панель.
4. Проверить «Серверная версия». После применения должна появиться строка с восстановлением локальной копии.
5. Нажать «Восстановить» и убедиться, что локальный вариант возвращается.
6. Повторить конфликт и проверить «Сохранить мою».
