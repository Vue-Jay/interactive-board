OnlineRepetitor v69 — корзина досок

Добавлено:
- обычное удаление теперь перемещает доску в корзину;
- удалённые доски исчезают у владельца и участников;
- отдельная «Корзина» на экране досок;
- восстановление доски со всеми связанными данными;
- окончательное удаление с отдельным предупреждением;
- доступ к корзине только у владельца.

Установка:
1. Извлечь содержимое архива в корень проекта.
2. node install_v69.mjs
3. Выполнить supabase/v69_board_trash.sql в Supabase SQL Editor.
4. npm run build

После успешной сборки:
git add .
git commit -m "v69: add board trash and restore"
git push

SQL-файл остаётся в supabase/.
