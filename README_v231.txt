OnlineRepetitor v231 — performance & stability audit

База: v230.
GitHub НЕ изменялся. Сначала локальная проверка.

Основные изменения:
- уменьшено число React-перерисовок при перетаскивании, resize, рисовании и realtime-курсорах;
- добавлено отсечение объектов далеко за пределами видимой области на больших досках;
- оптимизированы выборки выбранных объектов, слои, комментарии, поиск и другие вычисляемые списки;
- автосохранение больше не сериализует/хэширует всю доску на каждом нажатии клавиши;
- localStorage и серверное сохранение дебаунсятся и не дублируются;
- обновление метаданных доски на сервере ограничено по частоте;
- fingerprint документа заменён на компактный стабильный хэш без второго многомегабайтного JSON;
- IndexedDB для изображений/PDF использует одно переиспользуемое соединение;
- realtime-события комментариев/чатов объединяются в короткие пачки;
- realtime-канал согласования вложений получил backoff, offline/online обработку и защиту от reconnect-loop;
- уведомления не делают параллельные запросы при focus/visibility и не обновляются в фоне;
- внутренние переходы Материалы/Шаблоны/Уведомления работают без полной перезагрузки страницы;
- второстепенные экраны загружаются лениво, уменьшая стартовую нагрузку;
- убран старый bootstrap, который мог принудительно перезагружать страницу при смене версии;
- проверка новой версии больше не перезагружает текущую доску автоматически;
- история Undo имеет адаптивный лимит для тяжёлых досок, чтобы не раздувать память;
- изображения загружаются lazy/async.

Проверки:
- TypeScript (tsc -b): OK.
- Realtime tests: 12/12 OK.
- Полный существующий test suite: 26/31, ровно те же 5 старых падений, что и на v230; новых регрессий не появилось.
- Полный Vite build в служебной Linux-среде не запускается из-за Windows/native node_modules (Rolldown), а не из-за TypeScript-кода.

Архив содержит только изменённые файлы. Распаковать в корень проекта с заменой.
