OnlineRepetitor v43 — единый поток расписание → урок → история

Что сделано:
- исправлена загрузка расписания через отдельный безопасный RPC list_schedule;
- имя ученика и название доски теперь возвращаются сервером без хрупкой PostgREST-связи;
- занятие из расписания автоматически подготавливает ученика и тему на открытой доске;
- преподавателю остаётся нажать «Начать и запустить таймер»;
- Live Lesson сохраняет schedule_id;
- после завершения урока соответствующая запись расписания автоматически становится «Проведено»;
- запись занятия по-прежнему автоматически попадает в историю ученика;
- результат и домашнее задание сохраняются вместе с уроком;
- существующие ручные уроки продолжают работать;
- добавлена серверная проверка прав для завершения записи расписания.

Установка:
1. Выполнить supabase/v43_lesson_flow.sql в Supabase SQL Editor.
2. node install_v43.mjs
3. npm run build
4. После успешной сборки:
   git add .
   git commit -m "v43: connect schedule with live lessons"
   git push
