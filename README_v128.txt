OnlineRepetitor v128 — чат только внутри доски

Изменено:
- удалён переход в отдельный глобальный раздел «Сообщения» из кабинета и доски;
- чат использует только board_comments, поэтому история жёстко привязана к board_id;
- чат открывается выезжающей справа панелью поверх доски;
- панель можно свернуть кнопкой «−», работа с доской при этом продолжается;
- кнопка «Сообщения» находится на самой доске;
- на кнопке отображается счётчик новых сообщений;
- Realtime-подписка остаётся активной при свёрнутом чате, поэтому новые сообщения не теряются;
- при открытии чата счётчик сбрасывается.

SQL не требуется: board_comments уже привязаны к board_id и защищены RLS.
