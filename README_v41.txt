OnlineRepetitor v41 — аналитика прогресса

Что добавлено:
- новый раздел «Прогресс» в главной навигации;
- фильтр по ученику и периоду: 30 дней / 90 дней / год / всё время;
- KPI: количество занятий, часы, задания, процент проверенных, средний результат, просрочки;
- график среднего результата за последние 6 месяцев;
- круговая сводка по статусам заданий;
- таблица учеников: занятия, время, задания, просрочки, средний балл;
- последние занятия;
- переход в прогресс из карточки ученика;
- раздел доступен из «Досок», «Ученики» и «Задания»;
- использует уже существующие данные v35-v40, новая SQL-миграция не требуется.

Установка:
1. Скопировать содержимое архива в корень проекта.
2. node install_v41.mjs
3. npm run build
4. После успешной сборки:
   git add .
   git commit -m "v41: add student progress analytics"
   git push
