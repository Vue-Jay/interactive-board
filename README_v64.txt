OnlineRepetitor v64 — расширенные ссылки доступа

ВАЖНО: в этом архиве НЕТ вложенных v64_files. Ничего вручную по папкам переносить не нужно.
Положите ВСЕ файлы из архива в корень проекта.

1) node install_v64.mjs
2) Откройте Supabase -> SQL Editor и выполните весь v64_share_links.sql
3) npm run build

После успешной сборки:
git add .
git commit -m "v64: add expiring and limited share links"
git push

Добавлено:
- срок ссылки: 1 день / 7 дней / 30 дней / бессрочно;
- лимит использований;
- счётчик использований;
- серверная проверка срока и лимита;
- отображение срока и счётчика у активных ссылок.

Примечание по v62/v63:
если вы ранее вручную копировали файлы из v62_files/public или v63_files/public в public, это не ломает проект.
Установщики затем просто записали туда актуальные версии.
