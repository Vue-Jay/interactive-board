OnlineRepetitor v195 — LOCAL BOARD AI TOOL

AI is now a board tool instead of primarily a separate content studio.

Added:
- permanent robot icon in desktop toolbar;
- permanent robot icon in mobile tool dock;
- compact AI panel directly over the current board;
- generators for arithmetic examples, equations, word problems and mixed worksheets;
- Primary / Basic / Advanced levels;
- 3–15 generated items;
- preview and regenerate before insertion;
- one-click insertion as a native checklist assignment centered in the current viewport;
- generated items remain editable as normal board content.

Important:
This local build uses an offline generation engine so it works without external API keys. The UI/board workflow is now ready for a real AI provider later. Real model calls still require a server-side provider integration.
