OnlineRepetitor v156

Полная переработка мобильной доски по реальному скриншоту:
- удалена дублирующая нижняя панель быстрых инструментов;
- десктопная левая панель полностью скрыта на телефоне и появляется только по кнопке;
- внизу остаются только кнопка инструментов слева и компактный масштаб справа;
- огромная карточка «С чего начнём?» скрыта на мобильном;
- верхняя строка больше не прокручивается горизонтально;
- в шапке оставлены только название доски, участники/следование, чат и меню;
- поиск, комментарии, презентация, слои, undo/redo убраны из тесной мобильной шапки;
- панель инструментов открывается как компактная сетка поверх нижней части доски;
- звонки по-прежнему полностью скрыты и не являются частью активного интерфейса;
- «Рука» остаётся инструментом по умолчанию.
