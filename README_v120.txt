OnlineRepetitor v120

Исправление серверного сохранения новой доски.

Причина: в функции save_board_document переменная PL/pgSQL FOUND проверялась после SELECT профиля пользователя, а не сразу после SELECT board_documents. Для новой доски это могло ошибочно переводить функцию в ветку обновления несуществующего документа.

Что сделать:
1. Выполнить supabase/v120_fix_new_board_server_save.sql в Supabase SQL Editor.
2. Обновить файлы проекта из архива и выполнить обычный git push.

После миграции новая доска должна перейти в статус «Сохранено на сервере» после первого изменения.
