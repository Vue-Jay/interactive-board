OnlineRepetitor v40 — задания, сдача и проверка

Большой учебный блок:
- новый раздел «Задания» в главной навигации;
- преподаватель создаёт задание конкретному ученику;
- можно связать задание с доской;
- название, подробная инструкция, срок и максимальный балл;
- ученик видит свои задания в том же аккаунте;
- статусы: ожидает выполнения / на проверке / проверено;
- ученик отправляет текстовый ответ или комментарий к выполненной работе;
- повторная сдача сбрасывает предыдущую проверку;
- преподаватель видит ответ, выставляет балл и пишет обратную связь;
- ученик видит результат и комментарий;
- фильтры по статусу и сводные счётчики;
- переход из задания на связанную доску;
- удаление задания преподавателем;
- кнопка «Задания» добавлена прямо в центр управления живым уроком;
- отдельные RLS-политики чтения;
- сдача и проверка выполняются через SECURITY DEFINER RPC, поэтому ученик не может сам выставить себе балл или изменить отзыв преподавателя;
- локальный fallback сохраняется для режима без Supabase.

Установка:
1. Скопировать файлы архива.
2. В Supabase SQL Editor выполнить supabase/v40_assignments.sql.
3. node install_v40.mjs
4. npm run build
5. После успешной сборки:
   git add .
   git commit -m "v40: add assignments and review workflow"
   git push
