OnlineRepetitor v30 — «Следовать за преподавателем»

Добавлено:
- у участника, который не является владельцем доски, появляется кнопка «Следовать за преподавателем»;
- после включения экран автоматически повторяет текущую область и масштаб владельца доски;
- режим можно отключить в любой момент;
- обычные «Ко мне» и «Собрать всех» продолжают работать.

Поток сообщений:
- новый WebSocket НЕ создаётся;
- используется существующий низкочастотный board-view из v28;
- событие teacher_view отделено от focus_view;
- обновления преподавателя ограничены debounce 90 мс, то есть максимум около 11 сообщений/с во время движения;
- живые курсоры по-прежнему находятся в отдельном board-cursors;
- ученик игнорирует teacher_view, пока сам не включит режим следования.

SQL не нужен.

Установка:
1. Распаковать архив в корень проекта.
2. Выполнить:
   node install_v30.mjs
3. Затем:
   npm run build
4. Если сборка успешна:
   git add .
   git commit -m "v30: add follow teacher mode"
   git push

Проверка:
1. Открыть одну доску владельцем и вторым аккаунтом.
2. На втором аккаунте включить «Следовать за преподавателем».
3. На аккаунте владельца перемещать и масштабировать доску.
4. Экран второго аккаунта должен следовать за владельцем.
5. Выключить режим и убедиться, что экран снова становится независимым.
