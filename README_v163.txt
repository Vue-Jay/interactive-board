OnlineRepetitor v163

Переделана панель инструментов для сенсорной мобильной версии:
- постоянная аккуратная колонка слева;
- основные инструменты всегда доступны одним нажатием;
- крупные touch-target кнопки 44x44 px;
- активный инструмент заметно подсвечивается;
- дополнительные инструменты скрыты под кнопкой + и разворачиваются в этой же колонке;
- убраны дублирующие нижние mobile toolbar/launcher;
- панель сама прокручивается, если инструментов больше высоты экрана;
- отдельный компактный режим для телефона в landscape;
- «Рука» остаётся инструментом по умолчанию;
- верхняя панель и индикатор подключения из v162 сохранены.

Полные файлы для замены.
