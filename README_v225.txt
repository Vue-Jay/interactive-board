Исправления инструментов доски:
- точки графика по умолчанию чёрные; в редакторе у каждой точки можно выбрать цвет; двойное нажатие по графику на доске добавляет точку без открытия редактора;
- уменьшены маркеры изменения размера;
- из палитры фигур убран скруглённый прямоугольник, подпись прямоугольного треугольника перенесена на две строки;
- шторка стала простым непрозрачным прямоугольником с постоянной кнопкой-глазом снизу;
- режим «Выбор» снова подавляет нативное перетаскивание браузера и перемещает объекты;
- меню цвета и «Ещё» подняты над интерфейсом и открываются вниз;
- панель объекта скрывается во время открытого редактора;
- чекбоксы чек-листа квадратные, окно редактора прокручивается целиком;
- браузерный зум страницы отключён, масштабируется только доска.
