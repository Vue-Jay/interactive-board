OnlineRepetitor v51 — профиль и общие настройки

Добавлено:
- отдельный экран профиля;
- изменение отображаемого имени;
- тема: системная / светлая / тёмная;
- компактный режим интерфейса;
- настройка стартового масштаба доски;
- настройки синхронизируются через profiles;
- имя обновляется и в auth metadata.

Установка:
1. supabase/v51_profile_settings.sql
2. node install_v51.mjs
3. npm run build
4. git add .
   git commit -m "v51: add profile and app settings"
   git push
