OnlineRepetitor v74 — завершение базового блока резервных копий

Добавлено:
- «Скачать все мои»: единая копия всех собственных досок;
- формат .orworkspace;
- каждая доска сохраняется вместе со своими изображениями/PDF;
- восстановление набора досок из одного файла;
- предварительный просмотр состава копии;
- восстановление создаёт новые доски и не перезаписывает существующие;
- частичный сбой одной доски не останавливает восстановление остальных;
- прогресс экспорта и восстановления;
- серверный и локальный режимы.

SQL не нужен.

Установка:
1. Извлечь архив в корень проекта.
2. node install_v74.mjs
3. npm run build

После успешной сборки:
git add .
git commit -m "v74: finish workspace backups"
git push
