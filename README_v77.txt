OnlineRepetitor v77 — ссылки-презентации

Добавлено:
- для viewer-ссылки создаётся дополнительная ссылка «Ссылка-презентация»;
- параметр ?present=1 переживает гостевой вход / пароль ссылки;
- после успешного входа доска сразу открывается в презентационном режиме;
- доступ остаётся только для просмотра;
- обычная viewer-ссылка продолжает работать как раньше;
- выход из презентации у обычного пользователя очищает ?present=1.

SQL не требуется.

Установка:
node install_v77.mjs
npm run build

После успешной проверки:
git add .
git commit -m "v77: add presentation share links"
git push
