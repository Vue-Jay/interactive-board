OnlineRepetitor v31 — «Вести всех»

Завершаем блок управления экраном ученика.

Добавлено:
- у владельца в меню «В сети» появляется кнопка «Вести всех»;
- при включении все текущие участники сразу переносятся к преподавателю;
- после этого они автоматически следуют за его перемещением и масштабом;
- пока преподаватель ведёт группу, ученик не может случайно отключить следование;
- преподаватель может выключить режим кнопкой «Все следуют»;
- личный добровольный режим «Следовать за преподавателем» остаётся.

Realtime:
- новый WebSocket не создаётся;
- используется тот же board-view;
- guided_follow является отдельным редким управляющим событием;
- координаты по-прежнему идут через teacher_view с ограничением частоты;
- курсоры остаются в отдельном board-cursors.
SQL не нужен.

Установка:
node install_v31.mjs
npm run build

Если сборка успешна:
git add .
git commit -m "v31: add guided follow mode"
git push

Проверка:
1. Открыть доску владельцем и вторым аккаунтом.
2. Владелец: «В сети» -> «Вести всех».
3. Ученик должен сразу перейти к преподавателю и продолжать следовать.
4. Его кнопка следования должна быть заблокирована с текстом «Преподаватель ведёт экран».
5. Владелец нажимает «Все следуют», режим отключается.

Следующий блок roadmap: улучшение совместного редактирования и отображение того, кто сейчас редактирует объект.
