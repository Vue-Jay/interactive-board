OnlineRepetitor v50 — настройки и напоминания

Добавлено:
- переключатели типов уведомлений;
- напоминание перед занятием;
- напоминание о дедлайне задания;
- серверные события учитывают настройки;
- счётчик непрочитанных на главном экране;
- RPC generate_due_notifications для периодического запуска.

Для автоматических напоминаний RPC нужно запускать периодически через Supabase Cron. Патч не включает pg_cron автоматически.

Установка:
1. supabase/v50_notification_settings.sql
2. node install_v50.mjs
3. npm run build
