OnlineRepetitor v52 — форматирование текста

Добавлено для текста и стикеров:
- полужирное начертание;
- курсив;
- подчёркивание;
- выравнивание слева, по центру и справа;
- форматирование видно и во время редактирования;
- параметры сохраняются внутри документа доски;
- старые доски полностью совместимы.

SQL не требуется.

Установка:
1. node install_v52.mjs
2. npm run build
3. git add .
   git commit -m "v52: improve text formatting"
   git push
