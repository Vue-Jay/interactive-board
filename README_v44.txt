OnlineRepetitor v44 — библиотека материалов

Добавлено:
- рабочий раздел «Материалы» вместо заглушки;
- приватная серверная библиотека файлов;
- загрузка нескольких файлов до 50 МБ;
- папки/категории без отдельной тяжёлой сущности;
- поиск;
- фильтр по папкам;
- размер библиотеки и количество файлов;
- переименование и перенос между папками;
- скачивание;
- удаление метаданных и файла из Storage;
- отдельный приватный Supabase Storage bucket materials;
- RLS: каждый пользователь видит только собственную библиотеку;
- адаптивный интерфейс.

Установка:
1. Выполнить supabase/v44_materials.sql в Supabase SQL Editor.
2. node install_v44.mjs
3. npm run build
4. После успешной сборки:
   git add .
   git commit -m "v44: add materials library"
   git push
