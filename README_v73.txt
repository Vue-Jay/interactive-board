OnlineRepetitor v73 — импорт резервной копии как новой доски

Добавлено:
- импорт .orboard прямо с экрана «Мои доски»;
- предварительный просмотр: название, число объектов, вложений и формат;
- импорт создаёт новую доску, не перезаписывая открытую/существующую;
- перенос изображений и PDF;
- новые ID вложений;
- поддержка .orboard v2, старого interactive-board-bundle и обычного JSON;
- индикатор этапа импорта;
- после успешного импорта новая доска сразу открывается;
- работает и с серверным режимом, и с локальным режимом.

SQL не нужен.

Установка:
1. Извлечь архив в корень проекта.
2. node install_v73.mjs
3. npm run build

После успешной сборки:
git add .
git commit -m "v73: import backups as new boards"
git push
