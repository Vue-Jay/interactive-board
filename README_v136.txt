OnlineRepetitor v136 - полноценное восстановление WebRTC

Сделано:
- при disconnected выполняется ICE restart с новым offer;
- второй участник принимает повторный offer и автоматически отправляет новый answer;
- инициатор восстановления выбирается детерминированно, чтобы избежать одновременного ICE restart;
- обновлён service-worker cache с v122 до v136, чтобы клиенты быстрее получали актуальную оболочку.

Проверка:
- npx tsc -b: успешно;
- npm run build запускается и проходит TypeScript, но Vite в Linux-контейнере останавливается
  из-за отсутствующего native optional binding Rolldown. Это ограничение среды, не ошибка TypeScript.
