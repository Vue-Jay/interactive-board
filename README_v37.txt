OnlineRepetitor v37 — серверные карточки и история учеников

Это серверный этап блока «Ученики».

Что меняется:
- заметки преподавателя синхронизируются через Supabase;
- теги ученика синхронизируются между устройствами преподавателя;
- история занятий хранится на сервере;
- тема, итог, домашнее задание, длительность и связь с доской сохраняются в Supabase;
- данные разделены по teacher_id;
- включён RLS;
- преподаватель может работать только с карточками учеников, которые состоят хотя бы в одной его доске;
- занятие нельзя привязать к чужой доске;
- старые локальные данные v35-v36 автоматически мигрируют на сервер при первом открытии раздела;
- если миграция не удалась, локальные данные не удаляются и попытка повторится;
- локальный режим приложения продолжает работать без Supabase.

Установка:
1. Скопировать src и supabase из архива в проект с заменой/добавлением.
2. В Supabase SQL Editor выполнить файл supabase/v37_student_records.sql.
3. Запустить:
   node install_v37.mjs
   npm run build
4. После успешной сборки:
   git add .
   git commit -m "v37: sync student records with supabase"
   git push
