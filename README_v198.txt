OnlineRepetitor v198 LOCAL
Student permissions + teacher media approval.

Students:
- no AI robot;
- cannot create Checklist, Quiz, Flashcard, Cover, Table, Graph, Formula, Frame or link-media;
- blocked keyboard shortcuts cannot bypass this;
- retain handwriting, marker, eraser, text, sticky notes, comments and navigation;
- can interact with existing assignment widgets;
- image/PDF uploads are marked pending instead of approved.

Teacher:
- sees pending counter;
- sees the same pending media on the synchronized board;
- can preview, approve or reject;
- approval removes pending marker; rejection removes request.

QA:

npm run dev
