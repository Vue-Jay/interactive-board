# Платежи и тарифы — локальный этап

Цель: подготовить продуктовый и технический контур без реального списания денег.

## Локально реализуем
- модели тарифов Free / Teacher / Pro;
- feature gates и лимиты;
- экран текущего тарифа и сравнения;
- локальную имитацию смены тарифа для QA;
- состояния trial / active / past_due / canceled;
- точки интеграции checkout / webhook / customer portal.

## Не включаем без выбора провайдера
Реальные платежи, хранение платёжных реквизитов и production webhook. Эти части зависят от конкретного платёжного провайдера, страны юрлица и валюты.
