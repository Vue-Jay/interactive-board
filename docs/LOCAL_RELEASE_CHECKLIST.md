# OnlineRepetitor — финальная локальная проверка

Эта версия предназначена для полной проверки перед единственным веб-релизом.

## 1. Вход и роли
- регистрация, вход, выход;
- ученик / преподаватель / администратор;
- смена роли не оставляет права предыдущего пользователя;
- ученик не видит инструменты создания заданий.

## 2. Доски и синхронизация
- создать, переименовать, открыть и удалить доску;
- открыть одну доску в двух браузерах;
- изменения появляются у второго участника;
- повторное открытие восстанавливает содержимое и личную позицию камеры.

## 3. Инструменты
- Рука: тап выделяет, выделенный объект перемещается, свайп двигает доску;
- Выбор и Петля;
- карандаш, маркер, ластик;
- текст, стикеры, фигуры, связи;
- таблица, формула, график;
- тест, чек-лист, карточки, шторка;
- фото и PDF;
- нижняя панель выделенного объекта.

## 4. Мобильная версия
- портрет и альбом;
- верхняя панель не исчезает;
- в портрете нет панели масштаба;
- панели не перекрывают друг друга;
- pinch-to-zoom;
- перемещение изображений и PDF рукой.

## 5. Режим ученика
- можно писать, рисовать и решать задания;
- нельзя создавать/удалять/перестраивать преподавательские задания;
- нельзя обойти ограничение через Ctrl+K, Ctrl+D, Alt-drag, стрелки или контекстное меню.

## 6. Согласование вложений
- ученик отправляет изображение/PDF, но оно не появляется на доске;
- ученик видит «На согласовании»;
- преподаватель получает предпросмотр;
- несколько запросов образуют очередь;
- одобрение добавляет файл на доску;
- отклонение не добавляет файл;
- запрос повторяется во время временного reconnect realtime;
- после решения статус ученика исчезает.

## 7. AI
- робот доступен преподавателю на доске;
- запрос влияет на создаваемый материал;
- примеры, уравнения, дроби, геометрия, функции, проценты и текстовые задачи;
- результат проверяется до вставки;
- ученик не может создавать AI-задания.

## 8. Профиль, настройки и служебные экраны
- плитка профиля открывает профиль;
- настройки компактны и отделены от профиля;
- уведомления, материалы, расписание, задания и прогресс открываются без ошибок;
- PWA-установка не ломает обычный браузерный режим.

## 9. Перед веб-релизом
1. `npm run build`
2. Полный smoke-test на ПК.
3. Проверка реального Android в портрете и альбоме.
4. Проверка двух аккаунтов одновременно.
5. Только после этого один commit/push и один production deploy.

Реальные платежи и внешний AI gateway не включаются в локальный релиз без выбранного провайдера и серверных секретов.
