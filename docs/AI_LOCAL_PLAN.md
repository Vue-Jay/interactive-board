# ИИ-функции — локальный этап

Цель: подготовить UI и контракты, не вшивая API-ключи в браузер.

## План
- генерация задания по теме;
- генерация теста;
- генерация карточек вопрос/ответ;
- помощь с учебным материалом;
- серверный AI gateway вместо прямого вызова из браузера;
- подтверждение результата преподавателем перед вставкой на доску;
- лимиты, отмена запроса, ошибки и повтор;
- журнал использования без хранения секретов на клиенте.

Распознавание формул требует отдельного входа изображение/фрагмент доски и будет подключаться через тот же gateway.
