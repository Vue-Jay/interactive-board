OnlineRepetitor v45 — материалы становятся частью доски

Добавлено:
- кнопка «На доску» у материала;
- выбранный PDF или изображение автоматически вставляется при открытии доски;
- файл копируется из библиотеки в хранилище конкретной доски, поэтому существующая синхронизация досок продолжает работать;
- один материал можно повторно использовать на разных досках;
- избранные материалы;
- фильтр «Избранное»;
- счётчик использования и дата последнего использования;
- библиотека сортирует важные и недавно использованные материалы выше;
- неподдерживаемые для доски типы не вставляются и дают понятное сообщение.

Установка:
1. Выполнить supabase/v45_materials_board.sql.
2. node install_v45.mjs
3. npm run build
4. git add .
   git commit -m "v45: connect materials with boards"
   git push
